# rajas.signal

Personal link-in-bio site for **Rajas Naik** — built with the *Signal Terminal* design language.

> Warm amber on deep carbon. Aerospace instrument panel meets editorial typography.

## Stack

- **HTML5** — Semantic, accessible markup
- **Vanilla CSS** — Bespoke design tokens, no frameworks
- **Vanilla JS** — Live clock, scroll animations, parallax

## Design

| Token | Value |
|-------|-------|
| Surface | `#0b0a09` carbon black |
| Signal | `#e8a623` amber |
| Mono | JetBrains Mono |
| Serif | Instrument Serif |

## Deploy

Deployed automatically to **GitHub Pages** on push to `main` via `.github/workflows/static.yml`.
